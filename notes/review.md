复习周
① 文件与路径（11-19）
- 命令名必须精确：marik ≠ mkdir
- 路径黏连：daily-01.md~/labs 少空格 → 系统当成一个参数，报「缺少目标文件」
- 读报错：cp 说「缺少目标文件」= 只数到一个参数 = 少打了一个空格
- ~/notes ≠ 笔记目录，真笔记永远在 ~/projects/security-notes/notes/
② 符号（11-19）
- | 右边只能放命令，不能放文件；grep 结构：grep 找什么 在哪找
- 系统目录从 / 开始，不带 ~（/var/log/auth.log，不是 ~/var/...）
- wc -l = 数行数（echo x | wc -l 数前面吐出几行）
- && = 前面成功了才跑后面，失败就停
块③ 用户与权限（11-19）
- whoami = 我是谁（一个词）；id = 身份证（uid + 全部组，含 27(sudo)）
- sudo 密码不回显是故意设计；系统日志要 sudo 才读得动
- /etc/passwd 里恰恰没有密码，真密码在 /etc/shadow
- shadow 里的 $6$ 是哈希，单向不可还原（打散了拼不回去）
- sudo 操作全留痕：谁、何时、哪个终端、以谁的身份、干了什么——查日志这动作本身也被记进去
